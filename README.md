# Overview
 • Developed a project for handwritten digit recognition using the MNIST dataset, employing a Convolutional
 Neural Network (CNN) model implemented in TensorFlow.
 • Designed and trained the CNN architecture, incorporating convolutional, pooling, and fully connected layers to
 effectively classify handwritten digits (0-9) with high accuracy.
 • Employed Gradio, Flask, and Streamlit frameworks to deploy the trained model, creating user-friendly interfaces
 for real-time digit recognition accessible through web applications.
 • Optimized the model by fine-tuning hyperparameters, improving performance metrics like accuracy, precision,
 and recall.
